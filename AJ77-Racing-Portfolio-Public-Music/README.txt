AJ77 RACING PORTFOLIO
====================

CONTENTS
- index.html: portfolio page
- style.css: responsive automotive racing design
- script.js: navigation, reveal animations, and music controls
- assets/: supplied portfolio photos and an original synthesized AJ77 racing theme

MUSIC
The portfolio includes assets/aj77-original-racing-theme.wav, an original instrumental generated for this website. It does not contain the uploaded commercial song or samples from it. You may use this custom track as the background music for this AJ77 portfolio. Keep the audio file in the assets folder so the player can find it.

CUSTOMIZE
- Replace images in assets/ to update the portfolio gallery and motorcycle showcase.
- Edit text and links in index.html.
- Edit colors and layout in style.css.

PUBLISH WITH GITHUB PAGES
1. Create a public GitHub repository named Portfolio (or use your existing repository).
2. Upload index.html, style.css, script.js, README.txt, and the entire assets folder.
3. Open repository Settings > Pages.
4. Choose Deploy from a branch, select main and /(root), then Save.
5. Your site will appear at https://YOUR-USERNAME.github.io/Portfolio/.
